# Fleet intelligence, power management and benchmarking (FR15–FR18, FR20)

## Collection design

Extend Hive.Windows telemetry/inventory collectors and Hive.Agent workers, retaining current resource budgets (idle CPU <1%, private working set <150 MiB provisional), bounded queues and local protection checks. Use native Windows APIs, targeted CIM (never Win32_Product), performance counters, SetupAPI/Configuration Manager, storage reliability counters and validated vendor-specific GPU/sensor interfaces. Optional sensor integrations require licence/SBOM review, signed dependencies, no unapproved kernel driver, and least privilege. Discovery at enrollment/startup, daily and on device change; sample dynamic counters at existing cadence or slower (temperature/SMART every 60–300s proposed). Unsupported/denied/stale fields null with reason, source, units, timestamp and capability. Do not enumerate evidence media as fleet assets automatically or read their contents; allowlisted managed system/scratch disks only for health probes. No command lines, paths or titles.

| Area | Fields / approach |
|---|---|
| CPU | Model, cores/threads, utilisation, clock, temperature and throttling where supported |
| GPU | Adapter/driver, utilisation by engine, dedicated/shared VRAM, temperature/power via supported vendor interfaces |
| RAM | Capacity, slots/speed where reported, usage and available bytes |
| Storage | Model/firmware/serial for managed disks, volume capacity, throughput, latency, temperature, health, SMART/NVMe wear; don't equate wear indicator with exact remaining lifetime |
| Network | Approved NIC identity, link speed, RX/TX, errors; MAC restricted to necessary WoL/asset scopes |
| Hardware | Manufacturer/model/serial, board, BIOS/UEFI, TPM/Secure Boot, monitors and permitted peripherals; changes recorded with before/after and confidence |
| Windows | Edition, architecture, DisplayVersion, build + UBR, installation date where reliable, observed KB/patch history, pending restart, BitLocker boolean/status only (no recovery keys) |

Windows policy is observation-only at first. Match edition/architecture/feature release and numeric build/UBR against explicit accepted set/range/minimum with optional upper bound, approved required KB if reliably observable, applicability and effective dates. A newer build is not automatically approved; missing/conflicting detection is unknown. Show compliant/outdated/ahead or unapproved/exempt/unknown/not applicable. Record version history and separate scope/priority conflicts; never override IT GPO/WSUS/MDM. Expiring exceptions trigger reassessment and notifications, not automatic install/reboot.

## Event health

Use System.Diagnostics.Eventing.Reader EventLogWatcher/EventLogReader and bookmarks for allowlisted channel + provider + event ID/version combinations. Start with WHEA, Disk/StorPort/NVMe, NTFS, Kernel-Power, BugCheck, WindowsUpdateClient, Service Control Manager, Application Error and Hive service events. Verify actual provider/event mapping on supported builds; event 41 indicates unexpected restart, not cause. Parse bounded structured fields locally; redact/omit messages, XML, paths, usernames, command lines, crash dumps and case identifiers. Store provider, ID, level, UTC, category, sanitised reason, occurrence count and device; fingerprint from channel/provider/record ID plus channel generation; detect cleared/rolled logs, gap and rebaseline, bounded lookback. No Security log ingestion by default. Policy-based windows, hysteresis, dedup, acknowledgement and recovery; critical event may alert immediately, repeat events aggregate. No diagnosis of hardware failure from one corrected error. Offline replay dedupes; alert on collector failures. Historical metrics aggregate using existing retention architecture; initial 7d raw, 30d minute, 180d hourly proposed pending capacity/privacy approval. Keep health evidence retention separately approved.

## Wake on LAN

Typed WakeRequest: target device, reason, optional schedule UTC/expiry, idempotency key, scope. Server checks Wake capability, enrolled target, approved MAC/subnet binding, fresh authorisation, rate limit and site isolation. Select approved online relay in target broadcast domain (agent initiates outbound HTTPS sync; no inbound management port). Device certificate binds relay; server grants short-lived one-target permit, relay validates local allowed interface/subnet and registered target MAC, sends limited magic packet to approved local broadcast using configured UDP port. No caller-provided destination/IP/payload, public broadcasts, cross-evidence-network relay, arbitrary packets or retry storms. Optional server-local sender only after Docker/network validation; do not assume routed broadcast works. Audit request/relay/attempt; expire/revoke queued jobs and recheck rights at scheduled execution. State requested → queued → sent → awaiting authenticated heartbeat → confirmed/timeout/failed/cancelled; sent ≠ powered on. Offline ≠ powered off; distinguish tested sleep/hibernate/shutdown capability and unknown. BIOS/NIC/driver/Windows power settings, wired network, VLAN and S-state test matrix; no automatic firmware changes. Wake-and-RDP requires a fresh heartbeat plus separate existing RDP policy/session/protection check; never auto-launch unattended. P8 remote relay only after approval; no tailnet dependency in LAN.

## Benchmark profiles

Versioned signed/approved profiles, fixed workload parameters and synthetic datasets with hashes; record tool version, CPU/GPU/driver/OS, power plan, ambient/thermal observations if available, duration, bytes/operations, raw units, repeats, median/variance and test errors. CPU single/multi, GPU compute/VRAM, memory bandwidth/latency, sequential/random storage, controlled network to dedicated endpoint, MD5/SHA1/SHA256 throughput (benchmark only), compression and optional validated synthetic AI/forensic workloads. Use allowlisted non-evidential scratch path with quota, cleanup and no raw disk writes. Network tests bounded and approved, not live evidence servers by default. No arbitrary benchmark binary/args from server; approved typed profiles only. Explicit user/maintenance consent, fresh local protection lock check, exclusive maintenance lease, no concurrent deployments, cancel on protected work or temperature/space limits. Record interrupted runs as invalid, clean scratch on restart. Compare only matching profile version and comparable settings; normalized score optional with documented baseline, not invented. No automatic benchmark schedule before performance/quality approval.
